# Security

If you believe you have found a security issue in the decision logic published here, please report it
privately:

**Email:** security@i-ops.com

Include enough detail to reproduce the issue. We aim to acknowledge reports within one week.

This repository contains pure decision modules only — no network endpoints, no credentials, and no
runtime. Reports about the full I-Ops product should go through the same address and will be routed
appropriately.
